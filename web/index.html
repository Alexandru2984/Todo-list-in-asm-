YOUR SPACE, YOUR DATA

A small app.
A clear set of promises.

Tasks live on the server. A protected cookie holds your workspace key. We don’t add advertising or task analytics. Task pages stay out of the public sitemap and ask search engines not to index them.

This is an anonymous workspace, not a password-protected account. Anyone with your recovery key has full access. Save it privately, export important tasks, and keep sensitive information elsewhere.

A FEW THINGS TO KNOW

Curious? Good.

Is this really built with Assembly?

Yes. The HTTP server, routing and file storage use x86_64 Assembly and Linux syscalls. Your browser handles the HTML, CSS and JavaScript interface. No runtime web framework is required.

How do I come back to my tasks?

Your browser remembers your workspace through a cookie. In “Workspace & backups”, save your recovery key before clearing cookies or moving devices. Without the key, we cannot recover anonymous access.

Can I restore an existing workspace?

Existing lists from the earlier version are supported. Keep this key private.

Are there any limits?

Each workspace holds up to 1,000 tasks. Titles allow up to 110 UTF-8 bytes; emoji and accented characters may use several bytes. Exports include all your current tasks.
